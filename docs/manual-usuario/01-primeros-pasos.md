# Manual de Usuario - Primeros Pasos

Bienvenido a MargenX. Esta guía te ayudará a dar tus primeros pasos en la plataforma.

## Cómo escribir importes y cantidades

Para facilitar la carga de datos y evitar errores, MargenX está adaptado al formato numérico de Argentina:

- **Decimales:** Utilizá la **coma (`,`)** para separar los centavos o decimales. Ejemplo: `1234,56`.
- **Miles:** Podés usar el **punto (`.`)** para separar los miles si lo deseás. Ejemplo: `1.234,56`.
- **Atajo para miles:** Si escribís un número con un solo punto seguido de exactamente tres dígitos (ejemplo: `1.234`), el sistema lo interpretará automáticamente como mil doscientos treinta y cuatro (`1234`), no como un decimal.
- **Formateo automático:** Al terminar de escribir y salir del campo, el sistema acomodará visualmente el número al formato oficial (ej. `1.234,56`) para que puedas confirmar de un vistazo que está correcto.

Si ingresás un texto inválido (como letras), el sistema te mostrará un error debajo del campo y no te permitirá guardar hasta que lo corrijas.
